The most recent changes to RBAC in your organization are related to the recent OpenShift Cluster Manager (OCM) RBAC updates. These changes affect the ability of users to view and provision clusters. Specifically: • Users may lose the ability to view and provision clusters after the recent OCM RBAC changes. • The error "Failed to create cluster: status is 500, code is 'CLUSTERS-MGMT-500'" may appear. • Only a subset of clusters (e.g., 3 out of 300) may be visible in OCM. • Users might see "Failed to retrieve the default configuration" when creating a new cluster. To restore access, add the "OCM Cluster Viewer" and "OCM Cluster Provisioner" roles to the "Custom default access" group. These changes can take up to 30 minutes to take effect. Top Recommendations

Critical
Implement query disambiguation for ambiguous org-context queries
Both T1 and T2 received vague, org-specific prompts. The agent should trigger a structured chip/button disambiguation pattern before answering or declining.
Critical
Rewrite the T1 refusal response using partner-first persona language
Replace "I'm sorry, but I don't have access…" with a collaborative redirect that suggests alternative paths (IAM settings, support ticket, specific docs).
High
Add RBAC/subscription-aware disclosure to capability limitations
When the agent cannot fulfill a request, it should disclose whether the limitation is a technical boundary, an RBAC restriction, or a subscription entitlement gap.
High
Enforce response length limits (3 lines per message block)
T2 produced 8+ bullet points in a single message. Long responses should be chunked across turns or collapsed behind an expandable control.
High
Add confidence disclosure when answering with generic support content
T2 answered an org-specific RBAC question with a generic support article. A confidence warning is required: "This answer is based on public docs and may not reflect your org's configuration."
Medium
Personalize the chatbot welcome to the authenticated user
Replace the generic multilingual greeting with a personalized opener: "Hi Insights QA — I can help you with…" and explicitly state capability scope.
Medium
Deploy expandable chain-of-thought and skill-router toast notifications
Advanced users should be able to expand reasoning steps. When the agent hands off to a support document retrieval skill, a toast notification should fire.
